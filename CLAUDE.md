## Skills

Project skills live in `.claude/skills/`. Use them whenever a task matches:

- `frontend-design` — always load and follow for any frontend or UI work (pages, components, styling, layout, UI copy).
- `ui-ux-pro-max` — UI/UX decisions: design systems, palettes, font pairings, accessibility, stack-specific UI guidance.
- `video-to-website` — turning a video into a scroll-driven animated website.
- `design` — logos, corporate identity, icons, banners, social images.
- `design-system` — design tokens and component specs.
- `brand` — brand guidelines, voice, and asset consistency.
- `ui-styling` — shadcn/ui and Tailwind implementation.
- `banner-design` — banners for social, ads, web, and print.
- `slides` — HTML presentation decks.
