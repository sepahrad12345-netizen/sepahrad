# سیمرغ 🔥

بازی پروازی سه‌بعدی با داستان حماسی: سوار بر سیمرغ، از البرز تا دماوند پرواز کن، دیوها را بران
و ضحاکِ ماردوش را شکست بده تا آخرین آتش ایران خاموش نشود.

- **سه خان:** دره‌های البرز (غول آخر: دیو سپید) · کویر لوت (کلوت‌ها و طوفان شن) · قلهٔ دماوند (غول آخر: ضحاک و مارهایش)
- **کنترل:** کشیدن انگشت یا ماوس برای پرواز، شلیک خودکار، Space یا دکمهٔ «فرّ» برای قدرت ویژه، P برای مکث
- **موسیقی:** سنتور و دف در دستگاه شور، ساخته‌شده با Web Audio
- **اجرا:** فایل `index.html` را در مرورگر باز کن (به اینترنت برای three.js نیاز دارد)

بازی قبلی (شهر من) در پوشهٔ `shahr-man/` است.
