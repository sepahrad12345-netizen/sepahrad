# سیمرغ 🔥

بازی پروازی سه‌بعدی با داستان حماسی: سوار بر سیمرغ، از البرز تا دماوند پرواز کن، دیوها را بران
و ضحاکِ ماردوش را شکست بده تا آخرین آتش ایران خاموش نشود.

- **سه خان:** دره‌های البرز (غول آخر: دیو سپید) · کویر لوت (کلوت‌ها و طوفان شن) · قلهٔ دماوند (غول آخر: ضحاک و مارهایش)
- **کنترل:** کشیدن انگشت یا ماوس برای پرواز، شلیک خودکار، Space یا دکمهٔ «فرّ» برای قدرت ویژه، P برای مکث
- **موسیقی:** سنتور و دف در دستگاه شور، ساخته‌شده با Web Audio
- **اجرا:** فایل `index.html` را در مرورگر باز کن (به اینترنت برای three.js نیاز دارد)

بازی قبلی (شهر من) در پوشهٔ `shahr-man/` است.

# چاپار ✉ (`chapar/`)

بازی داستانیِ زنده: تو چاپارِ تازه‌ی دهِ سنگ‌چینی و هر نامه‌ای از دستت می‌گذرد. نامه را تحویل بده، مهرش را بشکن و بخوان،
با موم دوباره مهر کن، بازنویسی (جعل) کن، نگه دار یا بسوزان؛ روزی یک نامه هم خودت بنویس. شب‌ها Claude ده را شبیه‌سازی می‌کند:
هر کس فقط به آنچه واقعاً به دستش رسیده واکنش نشان می‌دهد و نامه‌های فردا را می‌نویسد. پس از هفت روز، پایانِ داستان و لقبِ تو نوشته می‌شود.

# کلان‌شهر 🏙️ (`kalanshahr/`)

بازی نقش‌آفرینیِ جهان‌باز و چندنفره در شهری شبیه تهران: کار پیدا کن (تاکسی، پلیس، بار، مسابقه)، ماشین بخر، گاوصندوق باز کن و کاراکتر جمع کن.

- **گرافیک:** کاراکترهای سه‌بعدیِ واقعی با انیمیشن، ماشین‌های ایرانی با پلاکِ ایران و رنگِ براق، نمای ساختمان‌های تهرانی با مغازه‌های فارسی، جوی و چنار، تیر چراغ‌برق، روز و شبِ کامل
