# شهر من 🏙️

بازی ادغام‌کردنی با حال‌وهوای ایرانی: دو ساختمان یکسان را به هم بزن تا ساختمان بزرگ‌تری بسازی،
از 🧱 آجر تا 🗼 برج میلاد.

- **کنترل:** انگشت (یا ماوس) را بکش و رها کن. روی کامپیوتر: ← → و Space.
- **لیگ شهرها:** در نسخه آنلاین، رکورد هر بازیکن به امتیاز شهرش اضافه می‌شود.
- **اجرا:** فقط فایل `index.html` را در مرورگر باز کن؛ هیچ نصبی لازم نیست.
